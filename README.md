# 🌙 Unsaid Talks

> Some thoughts just need to be heard.

Unsaid Talks is a simple anonymous thought-sharing platform where people can share their thoughts and read what others are feeling — without judgment.

## ✨ Features

- 📝 Share thoughts anonymously
- 👂 Listen to thoughts shared by others
- ⭐ Rate thoughts
- ✨ Random thought for inspiration
- 💾 Stores shared thoughts using SQLite
- 🎨 Simple and peaceful user interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
